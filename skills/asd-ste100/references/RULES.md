# ASD-STE100 rule reference

This file gives the writing rules of ASD-STE100 Issue 9. The rules come from Part 1 of the standard. Use this file with the main skill file.

The standard has nine sections of rules. Sections 1 to 9 give the rules. The general recommendations (GR) give extra help. They are not rules.

## Section 1: words

| Rule | Statement |
|---|---|
| 1.1 | Use approved words, technical nouns, or technical verbs. |
| 1.2 | Use an approved word as its specified part of speech. |
| 1.3 | Use approved words with their approved meanings only. |
| 1.4 | Use the approved forms of verbs and adjectives only. |
| 1.5 | Use words that fit a technical noun category. |
| 1.6 | Use a non-approved word only as a technical noun. |
| 1.7 | Do not use a technical noun as a verb. |
| 1.8 | Use the technical noun that your industry approves. |
| 1.9 | Use a short technical noun that is easy to understand. |
| 1.10 | Do not use regional, slang, or jargon words. |
| 1.11 | Do not use different technical nouns for the same item. |
| 1.12 | Use verbs that fit a technical verb category. |
| 1.13 | Do not use a technical verb as a noun. |
| 1.14 | Use American English spelling. |

### Technical noun categories

The standard gives 22 categories of technical nouns. Use the category that fits the term.

1. Official parts information.
2. Vehicles, machines, and locations on them.
3. Tools, support equipment, and their parts.
4. Materials, consumables, and unwanted material.
5. Facilities, infrastructure, and logistic procedures.
6. Systems, components, circuits, and their functions.
7. Mathematical, scientific, and engineering terms.
8. Navigation and geographic terms.
9. Numbers, units of measure, and time.
10. Quoted text.
11. Professional roles, groups, and organizations.
12. Parts of the body.
13. Personal effects, food, and beverages.
14. Medical terms.
15. Official documents and standards.
16. Environmental and operational conditions.
17. Colors.
18. Damage terms.
19. Computer science and communication technology.
20. Civil and military operations.
21. Law and regulations.
22. Animals, plants, and other life forms.

### Technical verb categories

The standard gives 4 categories of technical verbs.

1. Manufacturing processes.
2. Computer processes and applications.
3. Instructions for subject fields.
4. Law and regulations.

## Section 2: multi-word nouns

| Rule | Statement |
|---|---|
| 2.1 | Write a multi-word noun of 3 words or fewer. |
| 2.2 | Write a long technical noun in full the first time. Then use a shorter form or hyphens. |

A hyphenated group counts as one word. Use a hyphen for related words only. Do not hyphenate a group of more than 3 words.

## Section 3: verbs

| Rule | Statement |
|---|---|
| 3.1 | Use the verb forms in the dictionary only. |
| 3.2 | Use the infinitive, command, simple present, simple past, simple future, and past participle forms only. |
| 3.3 | Use the past participle form as an adjective. |
| 3.4 | Do not use auxiliary verbs to make complex tenses. |
| 3.5 | Use the `-ing` form only in a technical noun. |
| 3.6 | Use the active voice. Use the passive voice only when the agent is unknown. |
| 3.7 | Use a verb to describe an action. Do not use a noun for the action. |

## Section 4: sentences

| Rule | Statement |
|---|---|
| 4.1 | Write short and clear sentences. |
| 4.2 | Do not omit words. Do not use contractions. |
| 4.3 | Use a vertical list for complex text. |
| 4.4 | Use connecting words to connect related sentences. |
| 4.5 | Use an article or demonstrative adjective before a noun when applicable. |

Vertical list rules:

- Put a colon at the end of the sentence before the list.
- Start each item with a capital letter.
- Use a period at the end of a full sentence item only.
- Do not use a comma or semicolon at the end of an item.
- Use a period at the end of the last item.
- Do not mix procedural and descriptive items in one list.

## Section 5: procedural writing

| Rule | Statement |
|---|---|
| 5.1 | Use 20 words or fewer in each sentence. |
| 5.2 | Write one instruction in each sentence unless two actions occur at the same time. |
| 5.3 | Write instructions in the command form. |
| 5.4 | Write the condition first. Divide the condition from the command with a comma. |
| 5.5 | Write a note to give information only. Use 25 words or fewer in each note sentence. |

## Section 6: descriptive writing

| Rule | Statement |
|---|---|
| 6.1 | Give information gradually. |
| 6.2 | Use key words to give the text a logical structure. |
| 6.3 | Use 25 words or fewer in each sentence. |
| 6.4 | Use paragraphs to show related information. |
| 6.5 | Give each paragraph one topic only. |
| 6.6 | Use 6 sentences or fewer in each paragraph. |

## Section 7: safety instructions

| Rule | Statement |
|---|---|
| 7.1 | Use `WARNING` or `CAUTION` to show the level of risk. |
| 7.2 | Start with a clear and accurate command or condition. |
| 7.3 | Give an explanation that shows the risk or result. |

Use `WARNING` for risk of injury or death. Use `CAUTION` for risk of damage to objects.

## Section 8: punctuation and word count

| Rule | Statement |
|---|---|
| 8.1 | Use all standard punctuation marks except the semicolon. |
| 8.2 | Use hyphens to connect related words. |
| 8.3 | Use parentheses for references, identifiers, alternatives, and explanations. |
| 8.4 | A colon has the same effect as a period in a vertical list. |
| 8.5 | Text in parentheses counts as one word. |
| 8.6 | Count numbers, units, abbreviations, identifiers, quoted text, and titles as one word each. |
| 8.7 | A hyphenated group counts as one word. |

## Section 9: writing practices

| Rule | Statement |
|---|---|
| 9.1 | Use a different sentence construction when a word replacement is not enough. |
| 9.2 | Use each approved word correctly. |
| 9.3 | Do not make phrasal verbs. |
| 9.4 | Use a consistent style for the same task. |

### General recommendations

- GR-1: Use the word `that` after `make sure`, `show`, and `recommend`.
- GR-2: Read the sentence again when you use the word `with`. Prevent ambiguity.
- GR-3: Use approved pronouns only. Replace a pronoun that can have two meanings.
- GR-4: Use the word `this` only when the reader knows the item.
- GR-5: Do not use false friends. Use the English meaning of the word.
- GR-6: Do not use Latin abbreviations such as `e.g.`, `i.e.`, and `etc.`
- GR-7: Use inclusive language. Do not use gender-specific pronouns.
- GR-8: Use the possessive form correctly or use a different construction.
